1.Install dependencies:
npm install

2.Create local env file:
copy .env.example .env

3.Update .env:
LLM_PROVIDER=openrouter
OPENROUTER_API_KEY=your_key_here
OPENROUTER_MODEL=openai/gpt-4.1-mini
LLM_MAX_TOKENS=32000
OPENROUTER_MAX_TOKENS=32000
ALLOW_UNAUTHENTICATED_RUNS=true

4.Build once to verify:
npm run build

5.Start dashboard on port 3002:
npm run dev -- -p 3002

6. Open browser:
http://localhost:3002

7. For deployment testing, make sure Rancher Desktop is running.

8. In the dashboard:
Upload requirement/mockup images.
Optional: choose product-assets/aurum-watches.
Optional: enable auto-download product assets.
Click Run AI Team.
